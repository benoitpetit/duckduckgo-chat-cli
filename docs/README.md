# API documentation

The files in this directory describe the local HTTP API. `internal/api/docs.go`
contains the annotations used to generate them.

## Files

- `docs.go` contains the generated Go specification.
- `swagger.json` and `swagger.yaml` contain the same specification in JSON and
  YAML formats.

The API documentation is regenerated by `./scripts/build.sh`, the CI workflows,
and `./scripts/generate-docs.sh`. To regenerate it by hand, run:

```bash
./scripts/generate-docs.sh
```

The CLI command list comes from `internal/command/command.go`. The interactive
`/help` screen and dashboard use that registry.

When the API server is running, open the Swagger UI at:

```
http://127.0.0.1:8080/doc/index.html
```

Edit the annotations in `internal/api/docs.go`, then run the generation script
and commit the source and generated files together. Release checks compare the
generated documentation with its source.
